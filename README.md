# Code5 Launcher

Лаунчер Minecraft для сервера Code5: `65.108.18.26:25790`.

## Возможности

- Автоматическая установка и обновление модов из релизов Code5.
- Выбор PNG-скина с интерактивным 3D-превью.
- Поддержка обычной и тонкой модели рук.
- Автоматический вход на сервер после запуска Minecraft.
- Автоматическое обновление и перезапуск самого лаунчера.
