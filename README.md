# Code5 Launcher

Лаунчер Minecraft для проекта Code5.

## Возможности

- Автоматическая установка и обновление модов из релизов Code5.
- Аккаунт Code5 с выбранным игровым ником, регистрацией по электронной почте и подтверждением шестизначным кодом.
- Безопасное хранение входа и восстановление забытого пароля через почту.
- Защищённый одноразовый допуск на сервер: без входа через лаунчер подключиться нельзя.
- Выбор PNG-скина с интерактивным 3D-превью.
- Стандартный скин Hermit уже установлен и автоматически применяется в игре.
- Поддержка обычной и тонкой модели рук.
- Тёмная, светлая и системная темы оформления.
- Настройка памяти для Minecraft и вращения 3D-модели.
- Автоматический вход на сервер после запуска Minecraft.
- Возврат в лаунчер с сообщением после кика или потери соединения.
- Автоматическое обновление и перезапуск самого лаунчера.

## Сервер аккаунтов

Сервис аккаунтов и база PostgreSQL подготовлены для размещения на VDS. Инструкция по настройке находится в [auth-server/README.md](auth-server/README.md).
